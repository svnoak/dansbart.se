Drive playback spike

Usage: run npm run dev in frontend/ and open http://localhost:5173/scripts/drive-spike.html. Paste an OAuth access token with the drive.file scope and a Drive file id. Run the sections in order. Section 3 picks a file and fetches it with the token from section 1. The client id and API key prefill from VITE_GOOGLE_CLIENT_ID and VITE_GOOGLE_API_KEY.
